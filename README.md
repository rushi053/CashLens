# CashLens App Website

This is the website for CashLens, an expense tracking iOS app that helps users visualize and understand their spending habits.

## About CashLens

CashLens is a privacy-focused expense tracker that allows users to:
- Track expenses with custom categories
- Visualize spending patterns with beautiful charts
- Manage finances without sharing data to the cloud
- Export data in CSV or JSON formats

## Website Features

- Responsive design that works on all devices
- Modern UI with animations and interactive elements
- Detailed information about the app's features
- Privacy policy and terms of service pages

## Technologies Used

- HTML5
- CSS3 (with CSS variables, flexbox, and grid)
- JavaScript (vanilla, no frameworks)
- SVG for graphics and animations
- FontAwesome for icons

## Development

### Local Development

To work on this website locally:

1. Clone the repository:
```
git clone https://github.com/yourusername/CashLens-website.git
cd CashLens-website
```

2. Open the index.html file in your browser or use a local development server.

### Structure

- `index.html` - Main landing page
- `css/style.css` - All styles for the website
- `js/main.js` - JavaScript functionality
- `images/` - Contains all images and SVGs
- `privacy.html` - Privacy policy page
- `terms.html` - Terms of service page

## Deployment
